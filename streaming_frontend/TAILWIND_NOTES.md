This project is configured with Tailwind CSS.

Common commands:
- npm start            # runs CRA dev server
- npm run build        # builds production bundle

Environment variable:
- REACT_APP_API_BASE_URL to point the frontend to the backend (defaults to port 3001 on the same host).

Design tokens (tailwind.config.js):
- colors: primary(#63d64c), secondary(#71767f), error(#EF4444), background(#FFFFFF), surface(#f1f2f4), text(#111827)
